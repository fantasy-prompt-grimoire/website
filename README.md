# Fantasy Prompt Grimoire

Fantasy Prompt Grimoire（書籍購入者向け）は、AI画像生成用のプロンプトを
ワンクリックで組み立てられる無料ツールです。

Fantasy Prompt Grimoire is a free tool for book owners that lets you
build AI image-generation prompts with a single tap.

## 使い方 / How to use
1. 世界観・キャラクター・背景・雰囲気・線の太さをタップして選択 / Tap to choose a world, character, setting, mood, and line weight
2. 自動生成されたプロンプトをコピー / Copy the generated prompt
3. お好みの画像生成AIツールに貼り付けて、オリジナルのファンタジー塗り絵ページを作成 / Paste it into your favorite AI image tool to create your own fantasy coloring page
