# Fantasy Prompt Grimoire

Fantasy Prompt Grimoire（書籍購入者向け）は、AI画像生成用のプロンプトを
ワンクリックで組み立てられる無料ツールです。

## 使い方
1. 世界観・キャラクター・背景・雰囲気・線の太さをタップして選択
2. 自動生成されたプロンプトをコピー
3. お好みの画像生成AIツールに貼り付けて、オリジナルのファンタジー塗り絵ページを作成
